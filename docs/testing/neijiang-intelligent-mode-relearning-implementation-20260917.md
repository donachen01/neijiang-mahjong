# 内江麻将智能模式重学习实施与验证报告（2026-09-17）

## 结论

本轮已把四川麻将图片、PDF 知识复盘得到的可迁移机制落入内江麻将“智能模式”，并保持“透视模式”原有合同不变。代码、C# 运行时合同、Godot 状态机和 200 局候选/冻结基线对照均已完成验证。

200 局结果显示候选策略方向为正：候选总净分 `+72`，平均每局相对结果 `+0.360`；但 95% 置信区间为 `[-0.224, +0.944]`，仍跨过 0。因此本轮成果保留为智能模式候选策略，不自动晋级为已证明优于冻结基线的正式参数。这个边界是有意保留的，避免用小样本随机波动冒充“学习成功”。

## 已落地能力

1. **精确胡牌与听口分析**
   - 抽出共享的内江两门牌精确成牌分析器。
   - 同时覆盖普通四面子一将与七对；四张同牌在七对中按两对处理。
   - 弃牌、碰后弃牌、杠后补张分支复用同一规则入口，减少口径漂移。

2. **互斥牌块结构分析**
   - 新增互斥分解搜索，避免同一张实体牌被局部窗口重复计入多组搭子。
   - 输出完整组、对子、搭子、孤张、冗余块和最弱牌块质量，作为智能模式同向听比较的辅助信号。

3. **公平信息两步前瞻**
   - 每个候选摸牌分支会继续比较下一张弃牌，并在强路线中用精确听口重新核算活张。
   - 新增死分支概率和后 25% 尾部活张，避免只看平均值掩盖差分支。
   - 性能修正后不再对同一候选叠加两套前瞻：近听使用两步分支，较远牌型使用轻量前瞻；精确听口只细化最强 3 条路线。

4. **碰、杠、过与自回合杠决策**
   - 碰后弃牌比较加入精确听口和互斥结构。
   - 杠不再错误地“移除四张牌后直接弃牌”；现在严格模拟“成杠 → 按公开剩余牌概率补一张 → 直接胡或选择最佳弃牌”。
   - 补杠保持副露组数不变，暗杠增加副露组数；直接补张成牌不再被误记为最差活张分支。

5. **对手时序证据**
   - 弃牌证据加入时间衰减：近期主动放出的牌/花色比久远证据权重大。
   - 对已报叫或已副露玩家的放牌证据降权，避免把摸打牌错误解释成强烈“不要该花色”。

6. **学习与晋级门槛**
   - 单纯整局输赢只作为诊断，不再自动写入正式参数。
   - 新增逐决策 Brier 分数、后悔值和首选命中率校准。
   - 隐藏信息样本不得进入智能模式晋级；正式自动晋级要求独立测试集和至少 10,000 个决策节点。

## 验收边界与剩余风险

- 本轮最强证据到“源码构建 + C#/Godot 回归 + 独立逐张裁判 + 200 局候选/冻结基线对照”。没有把 200 局统计扩张成 10,000 决策节点正式晋级结论。
- 透视模式没有迁入智能模式的隐藏手牌、精确牌墙或三家协同信息；智能模式仍只使用本家和公开信息。
- 视频没有纳入本轮重学习来源；本轮依据为已有图片、PDF 及四川麻将代码成果。
- P95 尾盘性能仍高于预算。当前选择是保留近听分支质量并明确告警；后续若继续优化，应优先做跨候选状态缓存或预排序后的 Top-K 前瞻，而不是删掉精确规则或引入超时自动出牌。
- 报叫动作在 200 局固定场景中未触发（`bao_jiao_actions=0`），但报叫/报杠专项回归已通过；不能用这 200 局替代专项证据。
