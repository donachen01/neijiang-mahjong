本轮发生一次 `594.376ms` 峰值。P95 仍符合预算，但该单次峰值应标记性能警告。原始 200 局 JSON 生成时旧逻辑只按 P95 设置 `warning`，因此其中 `warning=false`；测试代码现已修正为 P95 超限或单次 `>=500ms` 都告警。

## 结论

- 逐张出牌正确性、可重复性、不卡局和 Mac P95 达到 1.0.60 门槛。
- 长期净胜分点估计已转正，但“老手长期显著领先”这一最高目标尚未被 200 局统计证明。
- 后续优化应优先针对六张 D 级样本和 594ms 峰值，不应继续无证据地扩大权重调参。
