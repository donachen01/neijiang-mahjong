## 1. 学习目标

本轮不以“记住若干固定出牌口诀”为目标，而是把资料中的方法拆成可验证的算法能力：

1. 精确且互斥的手牌结构分解；
2. 进张、听口与后续改良的条件概率；
3. 公开行为对暗手和牌墙位置的后验更新；
4. 普通牌、清色、七对、对子胡等路线的反事实比较；
5. 弃牌、碰、杠、过、报叫、报杠的统一净收益；
6. 用决策后悔值和概率校准代替按整局输赢粗调权重。

## 3. 重新学到的可迁移知识

### 3.1 结构不是局部特征之和

资料中的 `2234567`、`5567`、`4466`、刻子传递听口、四张同牌双重拆法等例子共同说明：

- 同一张牌不能同时被多个搭子重复占用；
- 一手牌必须比较多种互斥完整分解；
- 最弱结构往往决定整手牌的推进速度，即“木桶原理”；
- 有效张应计算并集，不应把重叠进张重复相加；
- 对子、顺子、刻子的价值随剩余牌组、轮次、公开张和可碰概率变化。

内江现有 `NeijiangHandShapeEngine` 主要累计局部相邻关系、对子压力和搭子溢出，尚未输出完整互斥分解。因此复杂连张可能同时获得多个局部奖励，却没有承担结构冲突成本。

**候选能力：** `NeijiangExactStructureEngine`

- 穷举合法顺子、刻子、对子、两面、边张、嵌张、孤张的互斥分解；
- 输出有效张并集、重叠损失、最弱块质量、结构冗余和路线兼容性；
- 允许多种等价分解共同保留，不提前锁死唯一解释；
- 为清色长连张、四张同牌、七对与普通牌竞争提供统一表示。

### 3.2 “活张”要区分牌墙概率和对手释放概率

资料明确区分：

- 某张牌仍未出现；
- 某张牌在牌墙中；
- 某张牌在对手手中；
- 对手摸到或持有该牌后愿意打出的概率。

因此同样是两张未知牌，熟张、刚被手切的生张、对手长期捏住的目标门牌，其可获得性不同。

**候选能力：** `NeijiangBehaviorLikelihoodEngine`

- 保存摸切/手切、弃牌顺序、过碰、过杠、报叫和副露事件；
- 对每个暗手粒子计算 `P(公开行为 | 候选暗手)`；
- 将牌墙概率、对手持有概率、未来释放概率分开输出；
- 对事件使用时间衰减，而不是只统计总弃牌数；
- 保持四张守恒和公开信息边界。

### 3.3 路线选择必须比较完整未来，而不是看起手阈值

资料对于做清、退清、七对、对子胡的共同原则是：比较未来收益，而不是看到若干张同门或若干对子就承诺路线。

**候选能力：** `NeijiangRouteCounterfactualEngine`

- 同时保留普通快叫、清一色、七对/龙七对、大对子/清对候选；
- 估计每条路线的成叫轮数、活听质量、结算净值、退出成本和尾盘失败概率；
- 路线切换使用迟滞门槛，避免一摸一打导致主路线抖动；
- 路线承诺只在净值差和置信度同时达标后发生。

### 3.4 宽窄色思想只能抽象为“供需压力”

四川资料中的宽色、窄色大量依赖三门牌和定缺，不能直接复制到内江。但其可迁移本质是：

- 某类牌被多少玩家需要；
- 某类牌有多少玩家会主动释放；
- 对子通过碰牌完成与顺子通过自摸完成的机会不同。

内江应改造成两门牌的 `SuitDemandPressure`：根据公开副露、弃牌顺序、过碰行为、报叫状态和剩余牌量，估计每门及每张牌的竞争压力、释放概率和阻塞概率。

### 3.5 碰、杠、过必须使用同一反事实时间线

资料中的“不盲目碰”“做清时中张刻子不急杠”“碰后能否立即成叫”“杠后补张收益”等原则不能靠固定奖励完整表达。

**候选能力：** `NeijiangUnifiedActionValueEngine`

- 过：保持手牌，等待下一次合法摸牌；
- 碰：移除两张，立即枚举最佳弃牌；
- 明杠：移除三张，先枚举补张，再胡牌或弃牌；
- 暗杠/补杠：加入抢杠胡风险、补张、后续弃牌和雨钱；
- 报叫/报杠：应用后续动作约束后再估值；
- 全部动作最终映射到内江正式结算净变化。

### 3.6 两步前瞻不能把进张等同于成功

资料的概率树和四川 `SichuanTwoPlyReadyEvaluator` 都强调：摸到进张以后还要重新弃牌，再观察形成什么听口。内江现有公平分支已有这个方向，但仍可补充：

- 完整听口拓扑；
- 多种分解产生的听口并集；
- 死分支比例；
- 最差分支之外的尾部均值/CVaR；
- 条件第二摸概率，而不是把边际牌墙概率当独立事件；
- 代理值与真实胡牌概率严格分名。

### 3.7 防守目标是减少净损失，不是机械打熟张

资料中的“防住大牌，别卡小牌”“防守有速度成本”“冲牌后能否迅速下叫”等内容，可以迁移为多目标决策：

- 自己未来收益；
- 点炮损失；
- 点碰、点杠导致对手推进的未来损失；
- 自己不成叫、查叫、退税损失；
- 分数位置和剩余局数对应的风险预算。

候选排序应先建立 Pareto 前沿：被另一个候选同时在速度、净收益和风险上支配的动作直接淘汰，避免大量互相抵消的加减权重。

### 3.8 学习对象必须从整局结果下沉到决策节点

内江现有学习引擎按整局净分、点炮率、自摸率、杠次数和流局率调整全局参数。它会把牌运和决策质量混在一起。

**候选能力：** `NeijiangDecisionLearningEngine`

- 每个决策记录公开状态、合法动作、候选分解、预测概率、预测净值和最终动作；
- 离线对同一状态进行候选动作反事实复演；
- 以决策后悔值、Brier 分数、校准曲线和排序一致率训练；
- 只有跨种子、跨座位和独立题库均改善时，参数才从影子模式晋升候选模式；
- 任何在线学习都不得读取智能模式本来不可见的真实暗牌。

## 4. 四川代码对照结论

### 已值得迁移的机制

- `SichuanTwoPlyReadyEvaluator`：逐个进张后重新枚举弃牌和听口；
- `SichuanMeldCounterfactualEvaluator`：过、碰、杠按不同时间线比较；
- `SichuanUnifiedDecisionEngine`：将动作统一为可比较净值；
- `SichuanHiddenHandInferenceEngine`：按公开事件更新候选暗手似然；
- 精确结构近分裁决、冻结基线、配对策略联赛和离线反事实评估。

### 只能继续处于诊断/候选状态的机制

- 公开联合路线、公开后验长程推演；
- 尚未校准为真实胜率的两摸代理值；
- 仅对特定候选开关生效的路线覆盖；
- 由课程例子支持、但没有长期净胜证据的阈值。

### 明确禁止复制的内容

- 定缺、换三张、血战离场与主动点走对手；
- 四川番值、四番封顶、根和查叫付款数值；
- 过胡后追求多家付款的四川专属收益；
- 任何透视信息进入智能模式。

## 6. 学习成果的验证门槛

1. **语义门槛**：每条知识有来源、适用条件、反例、内江适配和禁用范围。
2. **结构门槛**：PDF 牌型题库能断言互斥分解、有效张并集和听口集合。
3. **公平门槛**：相同公开状态不得因真实暗牌变化而改变正式智能决策。
4. **规则门槛**：AI 投影与 Godot 最终逐座位净分一致，覆盖抢杠胡、杠上炮、转雨和退税。
5. **动作门槛**：弃牌、碰、杠、过、报叫、报杠使用同一净值单位且时间线正确。
6. **统计门槛**：200 局仅作开发烟测；2,000 局作候选判断；多种子累计 10,000 局后，配对差值 95% 置信区间下界大于 0 才可替换正式策略。
7. **性能门槛**：Mac P95 小于 100ms，真机单独测量；同步正式链路不得超时降级或前端代打。
