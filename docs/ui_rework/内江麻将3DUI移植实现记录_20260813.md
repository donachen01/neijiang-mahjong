# 内江麻将 3D UI 移植实现记录

日期：2026-08-13

基线：内江麻将 `1.0.60`

视觉来源：四川麻将 `2.6.37` 的 3D 桌面、麻将牌、PBR 材质和 2D HUD 语言

## 1. 实施边界

本次改造只替换牌桌表现层和界面套件。以下内江麻将权威逻辑保持原入口：

- `GameState.state_changed` → `GameManager.snapshot_changed` → `MainSceneV2._on_snapshot_changed`
- 手牌点击仍进入 `_on_hand_tile_pressed(tile_id)`，第一次点击选择、第二次点击才尝试出牌。
- 胡、碰、杠、暗杠、补杠、报叫、报杠和过仍调用原有回调与 `GameManager.execute_action()`。
- 报叫/报杠选择仍使用 `human_bao_jiao_plan.bao_gang_options`，确认后调用原有 `execute_human_bao_jiao()` 链路。
- AI 调度、同步 C# 决策、开局报叫队列、计分和结算数据构造均未搬入 3D 组件。
- UI 不判断动作是否合法，不推进牌局阶段，不提供超时自动出牌、自动过或 AI 降级。

## 2. 新增表现架构

```text
GameState / GameManager
        │ snapshot_changed
        ▼
MainSceneV2（原有总调度）
        ├─ NeijiangTableStage3D：只读快照，发出 tile_pressed(tile_id)
        ├─ NeijiangSeatHUD：名字、分数、庄家、报叫/报杠、已胡
        ├─ NeijiangActionBar：最多六个数据驱动动作槽
        ├─ NeijiangUtilityBar：转发到原设置、辅助、明牌、结算、下一局和退出回调
        └─ 原报杠模态框 / 原内江结算数据 + 新 3D 视觉外壳
```

`NeijiangTableStage3D` 不引用 `GameState`，不调用规则或 AI。它只消费：

- 四家手牌、副露、弃牌和赢家状态
- 当前行动方、庄家、牌墙余量
- `human_can_discard`
- 选中牌、最新摸牌、推荐牌和风险牌标记
- 内江 `bao_gang_tiles`

## 3. 内江专属适配

- 手牌排序固定为条、筒两门，不读取或显示定缺。
- 中央计数使用快照 `wall_count`；不使用四川 108 张常量。
- 3D 报杠牌使用持续暖金标记，明牌和隐藏牌背都保留。
- 暗杠继续识别 `type == gang && gang_subtype == an_gang`。
- `SeatHUD` 用报叫/`杠×N` 徽章替代四川定缺徽章。
- 四席名牌采用四川最新版的墨玉漆面、古铜细框、末字玉石头像章与右上角庄家印章；当前行动方只用稳定双层铜环和细描边表达，不再叠加“出牌中”文字。
- 名牌位置沿用四川四席参考轨迹，对家移至右上、侧家避开竖向牌轨，并继续受安全区和视口缩放约束。
- 本家条、筒牌面纹样同步四川最新版实色 PNG，移除旧资源的白色描边；牌面与牌身保留四川 PBR 粗糙度/清漆参数，并仅校准本家暖象牙底色以匹配参考截图，禁止用无光照材质或自发光掩盖雾感。
- 动作条支持胡、杠、暗杠/报杠、碰、报叫/报杠、过同时出现。
- 四川查叫、花猪、定缺等数据未接入内江结算。

## 4. 输入合同

- 3D 牌面的屏幕投影命中后只发出稳定 `tile_id`。
- iOS 原生触摸与模拟鼠标事件按时间和位置配对去重。
- 动作条与工具条通过语义信号转发到原回调。
- 结算、AI 调参和报杠模态框可见时阻止底层 3D 手牌接收点击。
- 旧 2D UI 保留；3D 工具条可以切换旧版 UI，旧版右上角提供“切换 3D 牌桌”恢复按钮。

## 5. 资源生产链

资源由本机 Blender 5.2 LTS 重新生成，运行时不依赖四川工程或移动硬盘路径：

- `tools/3d/generate_neijiang_table_v2.py`
- `tools/3d/generate_neijiang_center_compass_v2.py`
- `tools/3d/generate_neijiang_ui_shells_v2.py`

## 6. 回退与偏好

`user://ui_prefs.cfg` 的 `main_scene_v2/neijiang_3d_table_enabled` 保存 3D/旧版 UI 选择；默认启用 3D。

回退只切换表现层，不重新初始化牌局，也不改变当前快照、AI 或规则状态。

## 9. 2026-08-13 图像对齐复核

按用户提供的内江/四川同屏截图重新核对后，纠正了两项偏差：

- 名牌不是“越亮越清楚”。四川当前设计依靠深色小面积底板、头像章、白色姓名/分数和低饱和古铜边建立层级；象牙白大卡会抢占牌桌视觉中心，因此已撤销。
- 手牌不是“越白越清楚”。此前白色牌体、自发光和旧纹样白边叠加，反而形成灰白薄雾；现在改为四川原始象牙 PBR 参数和深色实印纹样，以符号对比、牌缝和实体阴影提升清晰度。

## 10. 2026-08-13 牌体材质与工具抽屉复核

- 代码和 GLB 解析证明，内江与当前四川牌体共用同一种双实体层几何；发灰的主因是后期哑光材质和冷蓝补光，不是内江少了一层模型。
- 用本机 Blender 5.2.39 重新生成 `mahjong_tile_body.glb`，保留 0.074 翡翠背层 + 0.166 象牙牌身，总厚度 0.240。
- 本家牌面改为受光的暖象牙 PBR 承托面；不使用 unshaded 纯白牌面，字图印刷层则继续 unshaded 以稳定红绿颜色。
- 只影响麻将牌的冷蓝补光改为暖中性补光，翡翠背层恢复受控清漆高光和接触阴影。
- 难度、调参、辅助、明牌、结算、下一局、旧版 UI 和退出收纳到左上角。默认只显示折叠键，展开时水平排列；原 action ID、`utility_selected` 事件和 MainScene 回调不变。
- 详细层厚、颜色、材质与历史版本对比见 `docs/ui_rework/四川麻将牌体结构与内江迁移审计_20260813.md`。
- 后续实机反馈暴露出折叠键“能悬停但点不开”：原因是全屏 3D 输入和 Control GUI 路由未共享同一个状态入口。现在鼠标与触摸都经 MainScene 显式转发到 `activate_at_global_position()`，并对视口缩放下的重复原生按下去重；截图工具现在使用真实坐标点击，若第一次不展开或第二次不收起会直接返回失败。
- 本家名牌改为紧贴左下安全区定位，不再从本家手牌顶部反推 Y 坐标，从而与左家竖向牌列的末端完全分离。

本轮 Metal 实渲证据：

- `evidence/neijiang_3d_ui_port_20260813/tile_warm_pbr_expanded_1365x768.png`

## 11. 2026-08-17 私人牌室桌面与 AI 辅助收尾

- 按最终参考图把真实游戏桌面改为深翡翠均匀短绒、乌木化深框、深墨绿软包内轨和连续内外双香槟金镶线；两道桌布压线使用低对比翡翠色，不再增加中心角花或大面积金纹。
- 桌面几何仍由 Blender 5.2 LTS 生成，生产 GLB 内显式包含 `OuterChampagneGoldPiping`、`InnerChampagneGoldPiping`、`PlayfieldInsetOuter` 和 `PlayfieldInsetInner`，避免用 2D 贴图伪造立体镶嵌。
- 查明旧灰雾/云斑的资源链根因：Godot 的 GLB 导入读取 `res/art/3d` 中的提取贴图，而生成器此前只更新 `res/art/materials/table_v2`。生成器现在同步两套路径并强制导入，9 张 PBR 图的像素哈希已一致。
- 3D 模式不再把 `discard_helper_panel` 当作旧皮肤控件隐藏；辅助按钮继续沿用原事件入口，推荐/危险数据同时驱动 3D 标记和文字建议面板。面板按投影后的本家牌区定位并留出阴影安全间距。
- 真实场景的 1366×768 和 iPhone 2556×1180 捕获均通过满屏、铭牌避让和工具抽屉双击合同。捕获脚本已统一逻辑画布与物理视口坐标，防止缩放视口误报。
- 完整验收和移动包信息见 `docs/testing/neijiang-v1.0.72-premium-table-and-ai-helper-report.md`。
